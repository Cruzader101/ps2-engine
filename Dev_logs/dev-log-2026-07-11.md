## What broke & how I figured it out

- **Env, not code — `cl.exe: Cannot open include file: 'stdio.h'`.** Building from a plain
  shell fails because MSVC's `INCLUDE`/`LIB` env vars aren't set. Fix: run the build inside
  the VS dev environment — `vcvars64.bat && cmake --build build`. This is a per-shell thing,
  not a project bug. (Path: `...\18\BuildTools\VC\Auxiliary\Build\vcvars64.bat`.)
- **Macro line-continuation `\` missing.** Without a trailing `\` on each line, the `#define`
  ended at line 1 → the macro expanded to *nothing* and the `do{...}while(0)` body became
  loose statements at file scope (illegal). The `\` is what fuses the body into the one
  logical line a macro must be. (Counterpart to the `do/while(0)` lesson.)
- **Render placed *outside* the loop.** The `while(running)` body only drained events; the
  `glClear`/`SwapWindow` sat after the loop's closing brace, so they ran **zero times while
  the window was open** and once at shutdown → an uninitialised (garbage) window. Fix: move
  render + present *inside* `while(running)`. The rhythm of every frame is drain → render →
  present, all in the one loop. This was the load-bearing bug of the session.
- Typos caught in review: `gladLoadHL`→`gladLoadGL`, `CONTEX`→`CONTEXT`, two missing `;`
  (one showed its error on the *next* line — reminder that "error on line N" often means
  "mistake on line N−1").

## What I learned

- Links to concept notes: [[event-loop-double-buffering]], [[macro-line-continuation]]
  (candidates — not written yet).
- **GL attributes are wishes, not guarantees.** `SDL_GL_SetAttribute` requests 3.3 core;
  the driver can hand back something else and `CreateContext` still succeeds. The printed
  `glGetString(GL_VERSION)` *is* the verification, not decoration. May harden into a
  `PS2_ASSERT` on major/minor later.
- **Double buffering:** never draw to the visible buffer — draw to the hidden back buffer,
  `SDL_GL_SwapWindow` flips them whole, so no tearing. Without vsync
  (`SDL_GL_SetSwapInterval(1)`) the loop renders unbounded and pegs a core.
- **`SDL_Event event;` is a declaration** — `SDL_Event` is SDL's (union) *type*, `event` is
  my variable; `&event` is the address I hand `SDL_PollEvent` so it can write the popped
  event into my box. The bool return just says whether the queue had one.
